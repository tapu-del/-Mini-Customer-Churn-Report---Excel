# -Mini-Customer-Churn-Report---Excel
## About the Project
This is a beginner-level Excel project created to practice descriptive analytics on customer churn. The goal was to summarize customer data using Pivot Tables, visualize the difference in spending between churned and retained customers, and generate a business insight using AI.

## Tools & Skills Used
* Microsoft Excel
* Pivot Tables & Column Charts
* AI Tools (ChatGPT) for generating business insights

## Key Metrics Analyzed
* **Total Churned Customers:** 4
* **Total Retained Customers:** 4
* **Churned Monthly Charges:** ₹2,250
* **Retained Monthly Charges:** ₹5,300

## Key Insight
"Customers who churned have a lower total monthly charge (₹2,250) compared to retained customers (₹5,300). This suggests differences in spending patterns. The company should investigate factors like customer satisfaction, service usage, pricing, and quality to develop targeted retention strategies."
